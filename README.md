# Cyber Dashboard  

A modern cyber-security dashboard built with **React + TypeScript + Tailwind CSS + Lucide Icons**.  
It provides insights into projects, vulnerabilities, members’ activities, and real-time notifications with a clean UI.

## ✨ Features  

- 📊 **Dashboard KPIs** (Total Projects, Active Projects, Vulnerabilities, Clients)  
- 🍩 **Vulnerabilities Donut Chart** with criticality levels  
- 📈 **Projects by Type & Monthly Activity** with charts  
- 👥 **Members Activities** with smooth marquee scrolling  
- 🔔 **Notification Drawer** (slide-in panel on bell icon click)  
- 🌙 Responsive design with Tailwind CSS  

---


## ⚙️ Tech Stack  

- **React (TypeScript)** – Component-based UI  
- **Tailwind CSS** – Styling  
- **Lucide-react** – Icons  
- **Recharts** – Data visualization (bar & donut charts)
